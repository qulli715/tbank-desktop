# tbank — пополнения и чеки «Мой налог»

Десктопное приложение для Windows: анализирует **входящие пополнения** по карте Т-Банка
из CSV-выписки и помогает создавать чеки в **«Мой налог» (ФНС)**. Всё работает локально —
без браузера, без облака, без передачи данных наружу.

> Проект не связан с Т-Банком и ФНС. «Мой налог» работает через неофициальный API
> `lknpd.nalog.ru`, чеки создаются только по вашему подтверждению.

## Возможности

**Аналитика**
- 5 метрик: сумма, количество, средний чек, минимум, максимум.
- График поступлений по дням и круговая диаграмма по источникам.
- Treemap: порог по сумме источника, «Прочее», метрика «Сумма / Средний чек»,
  иерархия «источник → день»; клик по плитке фильтрует таблицу.
- Таблица всех пополнений: сортировка, ручное скрытие строк (скрытые не влияют на
  метрики и графики), поиск по имени, сумме, дате, описанию и категории.
- **Сводка и налог**: доход, оценка налога НПД по заданной ставке, количество чеков
  и сумма без чека, прогресс к годовому лимиту НПД; статус чека — прямо в таблице.
- **Массовые действия**: протяните мышью по таблице (прямоугольное выделение) и отметьте,
  скройте или перенесите сразу несколько поступлений.
- **Экспорт** текущей таблицы в CSV (Ctrl+E).
- **Drag & drop**: перетащите CSV-файл в окно — он импортируется.
- Фильтры по периоду и сумме, фильтр «Только без чека».
- **Настройки**: тема (системная/светлая/тёмная), какие графики показывать, наименование
  услуги в чеке и шаблоны, ставка налога (0–100%, дробная), подтверждение отправки.
- **Адаптивная раскладка**: окно работает на разных разрешениях и масштабах Windows
  (100–200%), на маленьких экранах панель инструментов уходит в меню-«ещё», сводка
  переносится на две строки, легенда графика сворачивается.
- Проверка обновлений (GitHub Releases).

**«Мой налог»**
- Вход по SMS (телефон → код), сессия сохраняется между запусками.
- Очередь чеков: отметьте поступления в таблице → «Перенести в «Мой налог»».
- Отправка чеков в фоне с прогрессом, подтверждение перед отправкой.
- Повтор упавших чеков, просмотр ошибок, поиск по очереди и отправленным.
- Удаление ошибочно поставленных в очередь чеков.
- Ссылки на отправленные чеки открываются в браузере.

**Импорт**
- CSV-выписка Т-Банка (кнопка «Импорт CSV…», Ctrl+O или меню «Файл»).
- Повторный импорт не создаёт дубликатов; уже существующие операции пропускаются.

## Установка

1. Скачайте `tbank-desktop-1.1.0-portable.zip` со страницы **Releases**.
2. Распакуйте в любую папку (например, `C:\Program Files\tbank` или на рабочий стол).
3. Запустите **`tbank.exe`**.

- **Windows 10/11 x64**, Python устанавливать не нужно — всё внутри.
- SmartScreen может предупредить, что издатель неизвестен (exe без цифровой подписи):
  «Подробнее» → «Выполнить в любом случае».
- При первом запуске рядом с `tbank.exe` появится папка `data/` — там хранятся база,
  бэкапы и настройки.

## Быстрый старт

1. В приложении Т-Банка: карта → **Операции** → **Выписка** → период → формат **CSV**.
2. В приложении: **«Файл → Импорт CSV…»** (Ctrl+O) и выберите скачанный файл.
3. Смотрите аналитику: метрики, графики, treemap; фильтруйте по дате и сумме.
4. Для чеков: отметьте нужные поступления галочкой **«Выбрать»** → **«Перенести в «Мой налог»»**.
5. Вкладка **«Мой налог»**: войдите по SMS → проверьте очередь → поставьте галочку
   «Я подтверждаю отправку в ФНС» → **«Создать чеки»**.

## Настройки

Меню **«Файл → Настройки…»** (Ctrl+,). Хранятся в `data/settings.json` рядом с базой.

- **Внешний вид**: системная / светлая / тёмная тема; какие графики показывать
  (линия, пирог, treemap).
- **Чеки**: наименование услуги по умолчанию и список шаблонов (в диалоге отправки можно
  выбрать или ввести своё); подтверждение перед отправкой. Название сохраняется
  в истории отправленных чеков; уже созданные чеки не меняются.
- **Налог**: ставка 0–100% с дробной частью (например, `3.4556435345`), быстрые кнопки
  4% и 6%. По умолчанию 6%. Это **оценка** для себя, а не налоговый расчёт ФНС:
  у НПД 4% с физлиц и 6% с юрлиц/ИП.

## Где хранятся данные

Все данные лежат локально, в папке `data/` рядом с `tbank.exe`:

| Файл / папка | Что это |
|---|---|
| `tbank.db` | база SQLite: пополнения, скрытия, очередь чеков |
| `backups/` | автоматические резервные копии БД (хранятся последние 7) |
| `app.log` | журнал приложения (ротация 1 МБ) |
| `.moy-nalog-session.json` | токены сессии ФНС (появляется после входа) |
| `settings.json` | настройки: тема, графики, услуга в чеке, ставка налога |

- Скопируйте папку `data/` для бэкапа или переноса на другой компьютер.
- Банковские логины, пароли и карты в приложении не хранятся — источник данных это CSV-файл.
- Вход в «Мой налог» — только по SMS; пароль и ИНН не сохраняются.
- Телеметрии нет. Сеть используется только для ФНС (вход и создание чеков).

## Ограничения

- Формат CSV-выписки может измениться на стороне банка — тогда потребуется обновление.
- «Мой налог» использует неофициальный API: возможны перебои, а VPN/блокировки могут
  мешать подключению к `lknpd.nalog.ru`.
- Чеки создаются **реально** — приложение не отправляет их без вашего подтверждения.
- Обрабатываются только пополнения: списания, покупки и комиссии игнорируются.

## Сборка из исходников (для разработчиков)

Нужен Python 3.11.

```bat
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-dev.txt
.venv\Scripts\python.exe main.py
```

- `run.bat` — запуск из исходников.
- `build_portable.bat` — сборка портативной версии в `dist\tbank` (PyInstaller, иконка).
  Данные из `dist\tbank\data` при пересборке сохраняются.
- `.venv\Scripts\python.exe -m pytest -q` — тесты (80, данные синтетические).

Структура:

```
main.py            точка входа, палитра, стиль
config.py          пути, .env, константы
core/              модели, аналитика, treemap, «Мой налог», логирование
storage/db.py      SQLite: схема, upsert, скрытия, агрегаты, бэкапы, очередь чеков
bank/csv_loader.py CSV-выписка Т-Банка -> SQLite (stdlib csv)
services/          состояние UI, импорт CSV, ФНС (сессия, вход, очередь, отправка)
ui/                главное окно, аналитика, «Мой налог», графики, таблица
tests/             pytest
```
